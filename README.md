# NexConnect DarkUI

A dark themed landing page for a BPO company, made with plain HTML, CSS and JavaScript.

## What it is

This is a single page website for a fictional company called NexConnect. It is a dark mode UI with a black background and yellow and indigo accent colors. Everything is in one file, so it works even without the internet.

The page has a navbar, a hero section, feature cards and a quote request form.

## Features

- Sticky navbar that gets a dark background when you scroll
- Hero section with headline, call to action buttons and a client logo strip
- A dashboard mockup made with pure CSS (stats, bar chart, floating response time widget)
- Three feature cards with hover effects
- A quote request form with name, email and requirement fields
- The form shows a confirmation message when submitted (demo only, no backend)
- Responsive layout that works on phones and tablets too

## Tech stack

- HTML5
- CSS3 (custom CSS, no frameworks)
- Vanilla JavaScript (navbar scroll effect, form submit handler)
- Inline SVG icons

There are no npm packages and no build step. Just open the file.

## How to view

1. Clone or download this repo.
2. Open `index.html` in any web browser. You can also right click and choose "Open with" your browser.

No server or internet connection needed.
